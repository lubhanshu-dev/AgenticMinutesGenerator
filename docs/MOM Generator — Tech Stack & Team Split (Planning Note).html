Planning Note: Tech Stack & Team Split

Agentic MOM Generator — 2-Person Team

Companion to the HLD. This note is working/planning material, not part of the formal design doc.

2. Team Split Rationale

The natural seam is where TranscriptAggregator hands off to MeetingOrchestratorAgent:

  • Before it → signal/speech processing (audio, ASR, diarization)
  • After it → language/agent logic + platform (orchestration, LLMs, API, monitoring)

This is a real architectural boundary — different skill sets, different failure modes, minimal shared state — not an arbitrary split.

5. Shared Contracts to Lock Down in Week 1

So neither person blocks on the other:

  1. Event schemas — exact fields for AudioFrame, TranscriptSegment, SpeakerLabeled, SessionStateChanged.
  2. Transcript data model — shape of the aggregated transcript object handed from Person A to Person B (speaker id, text, start/end timestamps, confidence).
  3. ILLMProvider interface signature — agree the contract early so mocking/testing isn't blocked on either side.

Once fixed: Person A develops against synthetic/mocked transcript events; Person B develops against a mocked transcript feed. Neither needs the other's code working to make progress.
